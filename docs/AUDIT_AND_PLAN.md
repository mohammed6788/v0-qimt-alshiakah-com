## 2) ما تم تنفيذه
- **الهوية**: ألوان مأخوذة من الشعار الرسمي (Navy `#011d45` / Silver `#c3c9d3` / Sky `#3db5e6` / Ivory). الشعار الجديد مستخدم كما هو دون تعديل (`public/brand/`) + أيقونات الموقع وصورة المشاركة OG.
- **الصفحات**: `/` · `/fabrics` · `/fabrics/[slug]` (6 صفحات) · `/design` · `/measurements` · `/about` · `/contact` · صفحة 404.
- **كتالوج الأقمشة**: بحث (يدعم اختلاف الهمزات والتاء المربوطة)، فلترة بالمنشأ والسعر، ترتيب بالسعر، صورة/اسم/منشأ/وصف/سعر/حالة توفر، زر التفاصيل، زر "اطلب هذا القماش عبر واتساب". دعم "السعر قبل الخصم" جاهز ويظهر فقط عند إدخال `compareAtPrice`.
- **صمم ثوبك**: 8 خطوات (القماش، اللون، الطراز والياقة، الأكمام، الأزرار، الإضافات والكمية والملاحظات، المقاس، المراجعة) + ملخص قابل للتعديل + رقم مرجعي + معاينة رسالة واتساب + شريط تحكم سفلي للاستخدام بيد واحدة.
- **المقاسات**: تسجيل بموافقة صريحة، حفظ على جهاز العميل فقط (localStorage)، استرجاع وتعديل وحذف، إعادة الطلب بنفس المقاسات عبر واتساب، إرسال المقاسات للمحل ليحتفظ بها، ودليل قياس. **لا توجد حسابات أو قاعدة بيانات** والنص في الصفحة يوضح ذلك بصدق.
- **نظام الطلب الموحد** (`lib/tailoring.ts → buildOrderMessage`): رقم مرجعي، الاسم، الرقم، المدينة، القماش والسعر، التفاصيل، المقاس، الكمية، الملاحظات – بترميز `encodeURIComponent` إلى `wa.me/967738360254`.
- **التواصل**: واتساب، اتصال مباشر (770051155)، إنستغرام، تيك توك، العنوان الجديد، خريطة Google مضمّنة، صورة واجهة المحل، توضيح استقبال الطلبات من خارج المكلا.
- **SEO**: عناوين ووصف وCanonical وOG لكل صفحة، Schema: Tailor/ClothingStore (LocalBusiness) + Product/Offer + ItemList + BreadcrumbList، sitemap بكل الصفحات والأقمشة، robots.
- **الأداء**: صور الهوية WebP، صفحات Static بالكامل، `next/image` مع lazy loading، خط Tajawal بـ `display: swap`، بدون مكتبات جديدة.
- **التحليلات**: `fabric_list_view`, `fabric_details_click`, `fabric_detail_view`, `fabric_search`, `design_start`, `design_step`, `order_submit`, `measurements_saved`, نقرات واتساب (مع تحويل Google Ads)، `phone_click`, `social_click`, `map_click`. مصادر الزيارات وعدد الزوار من Vercel Analytics تلقائياً.

## 3) الاختبار
- البناء `pnpm build` ناجح (18 صفحة Static).
- لا يوجد Horizontal Overflow ولا أخطاء JavaScript في جميع الصفحات على: 320 / 375 / 390 / 430 / 768 / 1024 / 1440.
- اختبار آلي لرحلة "صمم ثوبك" كاملة: التحقق من الحقول، توليد الرسالة، وحفظ المقاسات بالموافقة.

## 4) بيانات مطلوبة من صاحب المتجر (لم يتم اختراعها)
1. **معنى السعر المعروض**: هل هو سعر الثوب مع التفصيل أم سعر المتر؟ (حالياً: "سعر تفصيل الثوب" وهو آخر وصف استخدمتموه).
2. **حالة التوفر** لكل قماش (حالياً: "التوفر يُؤكد عبر واتساب").
3. **العروض الحقيقية** والسعر قبل الخصم إن وجدت.
4. **تأكيد بلد المنشأ** لكل قماش (مأخوذ من نوع القماش المسجّل: ياباني/كوري/صيني/تايلاندي).
5. **رابط إنستغرام**: الرابط الحالي `qimatalshiaka` بينما البنر يذكر `@qimtalshiakah` – أيهما الصحيح؟ ورابط تيك توك مأخوذ من البنر `@qimtalshiakah`.
6. **الألوان المتوفرة** لكل قماش وخيارات الياقة/الأكمام/الأزرار التي تقدمونها فعلاً (الحالية خيارات شائعة ويؤكدها المحل عند الطلب).
7. **صور عالية الدقة** لثياب مفصّلة وللمحل (صورة الواجهة الرئيسية الحالية مقتطعة من البوستر بدقة 572px).
8. رابط فيسبوك/يوتيوب/X إن أردتم إضافتها، وأوقات العمل لإضافتها للـ Schema.
